        About & credits

        Cool HK is a student group project for GEOG2147 Build Smart Cities with GIS (HKU). Routes are suggestions only: follow road signs and the Observatory's heat advice.

        Data, maps & services
        • Basemap & map labels: Lands Department, HKSAR Government — CSDI Portal / Map API
        • Temperature, humidity & heat warnings: Hong Kong Observatory Open Data API
        • Address search: Address Lookup Service (ALS), Digital Policy Office
        • Place search: GeoInfo Map location search, Lands Department
        • Shade on routes (covered walkways, footbridges, subways, indoor corridors, malls, tree rows): © OpenStreetMap contributors (ODbL), downloaded via the Overpass API into the app's own data file
        • Reference for future upgrade: 3D Pedestrian Network, Lands Department (CSDI)
        • MTR exits & station positions: © OpenStreetMap contributors (ODbL), via the Overpass API
        • Walking routes: OSRM hosted by FOSSGIS e.V., using OpenStreetMap data
        • Map engine, Topographic & Imagery basemaps: Esri ArcGIS Maps SDK for JavaScript and ArcGIS Online (HKU hkugeog organisation); imagery © Esri, Maxar, Earthstar Geographics
        • MTR line names & colours: MTR Corporation (used to identify lines only)
        • Walking directions hand-off: Google Maps URLs
        • Fonts: Bricolage Grotesque, Figtree, Noto Sans TC, JetBrains Mono, from Google Fonts (SIL Open Font License)
        • Hosting: GitHub Pages
        Course & project materials
        • GEOG2147 Build Smart Cities with GIS, The University of Hong Kong. Project brief by Prof. Winnie Tang and Mr Kelvin Shum
        • Cool HK group brainstorm and project outline (team document)
